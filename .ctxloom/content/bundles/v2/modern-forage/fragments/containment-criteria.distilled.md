# containment-criteria

Qualifies if ≥2 of: geographic containment (~100-200mi) | name-recognition failure | no national chain adoption | active local culture

Exclude: nationally famous icons (deep-dish, Philly cheesesteak, Nashville hot chicken, lobster rolls, fluffernutter)

## Sources
- **Min**: 2 independent named sources
- **Target**: 5-8 for canonical
- "Named": food media, local TV, longform, academic, podcast, oral history (NOT Reddit comments)
- Reddit = seed signal only

## Containment mechanisms
1. **Immigrant-community-locked** — Greek diners, Chinese-American, Cornish mining, German-Russian (most common)
2. **Apparatus-locked** — Chicago aquarium smoker, Provel, Old Vienna machinery
3. **Operational-routine-locked** — Pizza Pot Pie flip, Brown Hotel service
4. **Commitment-purchase-locked** — Atomic Cake whole-only, Pittsburgh Cookie Table wedding

## Geographic tiers
- **Hyperlocal** — single neighborhood/shop
- **City-wide** — multiple vendors/neighborhoods
- **Regional** — cross-metro coherent geography

Promote hyperlocal → regional when adjacent metros surface dish

## Partial-containment allowed
- **Two places, no national**: Walker Bros Apple Pancake (Portland → Chicago North Shore, both unknown)
- **Practice-locked, dish-escaped**: Flaming Saganaki (nationwide but flame/"Opa!" Chicago-locked; include w/ caveat)
- **Total media invisibility**: Beef Roll (dozens menus, no Wikipedia/NYT/LTHForum; local presence + zero media = strongest signal)

## Diaspora signal
#1 lead: "moved from X, can't find Y" = strongest seed. Treat primary; validate w/ named sources.
