# Banned Phrases

Statistically diagnostic of LLM output (Kobak 2025; Liang 2024; WP:AISIGNS). Fix = delete or restructure — never synonym-swap ("delve" → "dig into" keeps the tell).

## Hard bans
Verbs: delve, underscore, showcase, leverage, harness, foster, elevate, empower, streamline, unlock, unleash, embark, bolster, facilitate, revolutionize, navigate*
Adjectives: pivotal, crucial*, robust*, seamless, comprehensive, meticulous, intricate, multifaceted, transformative, groundbreaking, cutting-edge, ever-evolving, game-changing, invaluable, holistic, vibrant, nuanced*
Nouns: tapestry, landscape*, realm, testament, synergy, journey*, beacon, cornerstone, paradigm, myriad, plethora, treasure trove, insights*
(* = as filler or metaphor)

## Template bans
- "plays a crucial/key role in" → say what it does
- "stands as / serves as / is a testament to" → "is"
- "it's important/worth noting that" → just state it
- "in today's fast-paced world / digital age / ever-evolving landscape"
- "not only X but also Y"; "it's not just X — it's Y" → state Y
- "harness the power of"; "unlock the potential of"
- "navigating the complexities of"
- "in conclusion / in summary / overall" closers
- furthermore/moreover/additionally as paragraph glue

## Escape hatch
Fine as the precise technical term ("robust statistics") or in quotes. Banned as default register.
