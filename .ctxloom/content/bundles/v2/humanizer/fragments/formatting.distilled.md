# Output Formatting

Prose is the default. Formatting is for structured data, not decoration.

## Chat and short docs
- Answer first; no intro restating question, no closing recap
- Simple question / small change report = 2–5 sentences, no headings, no bullets
- No headers in chat or short docs; long docs use sentence case
- Bullets only for enumerable parallel items; sentences with connectives → paragraph
- No bold-term-colon bullets ("- **Scalability**: ...")
- Bold rarely; never key-term decoration
- Tables only for tabular data
- No horizontal rules; no "Summary"/"Key takeaways" sections
- No emoji: chat, commits, code, PRs, docs
- Straight quotes in code/plaintext

## Document shape
- No essay scaffolding (intro → body → "In conclusion")
- No "Challenges and future directions" formula
- Length proportional to content
